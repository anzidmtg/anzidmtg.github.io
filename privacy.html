Privacy policy

anzidbot · last updated 22 September 2026

anzidbot is a chat bot for the anzidmtg live streams. This policy describes what it accesses and what happens to that information. In short: it reads public chat as it arrives, acts on commands, and keeps nothing afterwards.

What it accesses

  • Public live chat messages on the channel's own broadcasts — the message text, the sender's public display name, and their public channel identifier. This is the same information anyone watching the stream can see in the chat panel.
  • Permission to post in that live chat as the bot account, so it can answer commands.

It requests one Google authorization scope, youtube.force-ssl, which is the scope YouTube requires to read and post live chat messages. It does not read, upload, modify or delete videos, playlists, subscriptions or account settings.

What it stores

  • No database, and no profiles. Nothing about a viewer is written to disk.
  • While a stream is running, the bot briefly holds recent message identifiers in memory so it does not answer the same message twice. This is discarded when the broadcast ends or the software restarts.
  • A viewer's display name appears in the bot's reply to them, in the live chat, exactly as it does when anyone replies to anyone. YouTube's own chat history governs that message, not us.
  • Ordinary operational logs on the broadcast machine may record that a command was used. They stay on that machine and are not published.

What it never does

  • No selling, sharing or transfer of information to anyone else.
  • No advertising, tracking, profiling or analytics.
  • No collection of email addresses, payment details or any other personal data.
  • No access to private videos, private messages, or any channel other than the one being streamed.

Google user data

anzidbot's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Children

anzidbot is not directed at children and collects no information from anyone, including children.

Changes and contact

If this policy changes, the date at the top of this page changes with it. Questions, or a request about anything above: anzidmtg@gmail.com.
